# JavaScript Quiz Application

A browser quiz app built with HTML, CSS, and vanilla JavaScript. The app shuffles questions, displays answer buttons, marks correct and wrong answers, and lets the user move through the quiz.

## Features

- Start button
- Randomized question order
- Dynamic answer buttons
- Correct/wrong visual states
- Next button between questions
- Restart behavior at the end

## How To Run

Open `index.html` in a browser.

## Files

```text
index.html
style.css
script.js
```

## What I Practiced

- Array-based quiz data
- DOM element creation
- Event-driven UI changes
- Class toggling for visual feedback
- Resetting UI state between questions
